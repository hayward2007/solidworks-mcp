# 기존 설계 대화에서 도출한 시스템 요구사항

2026-10-21, 사용자가 지정한 비공개 Claude Cowork의 Didean Walker v3 대화를
로그인된 브라우저에서 읽고 V7 Raked 비교 이미지를 시각적으로 확인했습니다.
보인 최근 메시지와 설계 근거 문서의 앞부분을 검토했습니다. 대화 전체, 회사의
Notion/Slack 원문, 원본 CAD, 계산 코드와 모든 첨부를 검증한 것은 아닙니다.
사내 자료와 원본 이미지는 이 저장소에 복제하지 않았습니다.

## 관측과 해석

기존 작업에는 여러 외형 대안, 전면 경사, 시야·질량·간섭·무게중심 비교와 근거
태그가 이미 존재합니다. 따라서 개선은 숫자나 렌더를 단순히 더 늘리는 데서 끝나면
안 됩니다. 각 비교의 원본 상태와 재현 조건을 연결하고, 실제 검증 범위를 제한해야 합니다.

검토한 보드에서는 카메라 돌출과 전체 전면 위치가 서로 다른 지표였습니다.
이를 하나의 "돌출 없음" 표현으로 압축하면 외곽 증가라는 tradeoff가 가려집니다.
시야율, 근거리 가시성, 유효 depth는 별개로 검토해야 합니다. 정적 자세의 간섭 수치도
전체 동작의 무간섭을 보장하지 않습니다.

근거 문서는 여러 revision의 변경과 철회를 기록하고 있었습니다. 이전 치수나
질량 보정이 최신 계산에 섞이지 않게 revision·artifact hash·configuration이 필요합니다.
회사 문서에서 인용했다는 사실은 이번 시스템이 그 원문을 다시 검증했다는 뜻이 아닙니다.

## 구현으로 연결한 항목

| 설계 품질 문제 | 시스템의 대응 |
|---|---|
| 렌더는 있으나 제조·정비 디테일이 후속으로 밀림 | 공차·조립·정비·공급사 확인·위험을 proposal 필수 필드로 지정 |
| 스타일 이름만으로 대안을 선택할 가능성 | silhouette/proportion/radius/seam/CMF와 시각 기준·증거 요구 |
| 수치는 있으나 재현 조건과 원본이 분산 | 원본 바이트 보존, 증거 locator/조건, revision별 계산 재실행 |
| 표준 태그와 검증된 원문이 혼동될 가능성 | authority와 적용 범위 명시; legacy 수치는 미검증 유지 |
| 한 번 승인한 뒤 형상이 계속 변함 | 변경된 revision은 재검토; 원본 해시가 바뀌면 handoff 차단 |
| 비용 절감을 위해 설명·이미지부터 줄임 | quality 기본, 필수 정책은 compact에서도 유지 |

이 문서는 기존 설계가 잘못되었다거나 모든 숫자가 거짓이라는 판정이 아닙니다.
사용자의 불만을 검토 가능한 설계 기준과 구현 요구사항으로 옮긴 기록입니다.
새 시스템의 예제 또한 실제 Walker의 개선 완료를 의미하지 않습니다.
